## 1. 适用范围

该模板用于为外部云电脑编写任务指令。云电脑不能访问当前 Codex 的 skill、命令目录
或本地对话，因此指令文档必须独立、完整、可复制执行。

默认保存为：

```text
D:\DOC\<project>\<instruction-name>.md
```

## 3. 文件大小与拆分

云电脑的单个命令文件不得超过 `10,000` 字符。建议在达到 `8,000` 字符时开始拆分，
避免接近上限后被截断。

多文件命令的规则：

- 所有文件放在同一个云电脑 `commands` 目录；
- 当前标准目标路径为 `C:\Users\liuziao\lingma\commands`；
- 必须有一个短入口文件，例如 `plot.md`；
- 入口文件按读取顺序列出所有配套文件；
- 使用同目录相对链接，例如 `[plot_style.md](plot_style.md)`；
- 每个文件都要独立低于限制；
- 拆分按职责进行，不按固定字符数机械截断；
- 配套文件缺失或无法读取时，云电脑必须停止执行。

推荐的职责划分：

```text
plot.md            任务入口、读取顺序、执行流程
plot_style.md      尺寸、字体、子图、图例和角标规范
plot_template.md   已验证代码模板
plot_validate.md   输出尺寸、视觉和失败处理
```

## 4. 必填内容

- 任务目标和不适用范围；
- 目标操作系统、解释器和软件版本；
- 默认输入、配置、程序和输出路径；
- 用户可覆盖的参数；
- 是否允许联网；
- 安装包的复制位置和校验方式；
- 按顺序编号的执行步骤；
- 每一步的成功条件；
- 最终文件格式和命名；
- 失败时停止的位置和保留的现场；
- 完成汇报必须包含的字段。

## 5. 路径与依赖

- 优先使用云电脑能看到的目标路径，不使用当前 Codex 的 `~/.codex` 路径。
- 当前电脑上的开发路径只能作为来源说明，不能假定云电脑存在相同路径。
- 需要复制包时，在文档中写清包名、目标目录和 SHA256。
- 离线安装命令必须保留 `--no-index` 和本地包目录。
- 数据、参数和输出路径按项目分目录，不直接落在磁盘根目录。

### 5.1 云电脑 Skill

云电脑默认提供 skill 目录：

```text
C:\Users\liuziao\lingma\skills
```

适合做成 skill 的内容：

- 会反复使用的稳定能力；
- 需要附带的 Python 或 PowerShell 脚本；
- 有明确触发条件和固定验证流程的任务。

云电脑 skill 的源目录：

```text
D:\DOC\cloud-skills\<skill-name>\
```

目录结构：

```text
<skill-name>\
|-- SKILL.md
|-- agents\
|   `-- openai.yaml
`-- scripts\
    `-- <helper>.py
```

复制方式：

- 直接复制完整的 `<skill-name>` 文件夹；
- 不压缩、不改名为 `.md` 单文件；
- 不复制 `__pycache__`；
- 复制目标为 `C:\Users\liuziao\lingma\skills\<skill-name>`；
- 复制后在云电脑中确认 skill 能被发现并调用。

## 6. 验证要求

- 能运行的代码先在当前环境测试；
- 每个待复制 Markdown 文件的字符数低于 10,000；
- 入口文件列出的配套文件全部存在；
- 同目录相对链接有效；
- 检查代码语法、退出码和实际输出文件；
- 检查输出文件非空、格式正确、尺寸或关键字段合理；
- 没有验证的部分明确写出；
- 运行 Markdown 审计，确保目录、代码块和链接有效；
- 不把尚未测试的示例写成已通过。

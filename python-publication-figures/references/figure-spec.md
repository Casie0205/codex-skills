## 1. 适用范围

该规范用于当前 Codex 生成报告、论文和阶段性总结中的 Matplotlib 图片。每张图只
回答一个视觉问题。多个不相关主题应分别生成独立图片。

导航输出的默认数据源是运行输出目录中的 `ins_insplot.txt`。绘图前先确认列定义。
如果第 3 至 5 列是经纬高，而绘图主题是米制位移或轨迹，必须先运行
`scripts/convert_navplot_enu.py`，再使用生成 CSV 中的 `elapsed_s`、`east_m`、
`north_m`、`up_m`。不得把经纬度直接当作 E/N 米制坐标。

## 2. 依赖

使用：

```python
import matplotlib
import numpy as np
import pandas as pd
from matplotlib import pyplot as plt
```

在导入 pyplot 前使用无界面后端：


## 3. 图形尺寸

A4 宽度为 210 mm，图片宽度固定为 A4 的 `2/3`：

```text
figure width = 140 mm
```

Matplotlib 使用英寸：

```python
MM_PER_INCH = 25.4
FIGURE_WIDTH_IN = (210.0 * 2.0 / 3.0) / MM_PER_INCH
```

高度根据子图数量计算。模板默认每个子图约 `1.62 in`，再叠加边距和图例所需间距。

禁止使用 `tight_layout()` 或 `bbox_inches="tight"`，避免导出宽度偏离 140 mm。

## 4. 子图布局

- 子图默认单列纵向排列；
- 面板共用横轴时只在最下方子图显示横轴标题；
- 每个子图都必须有纵轴标题；
- 纵轴标题必须包含单位，例如 `位置 (m)`、`速度 (m/s)`；
- 纵轴标题统一旋转 90 度，并固定在同一图形横坐标；
- 纵轴标题顶部与各子图顶部对齐；
- 左侧留出足够边距，标题不得压住刻度数字；
- 每个子图左上角只放 `(a)`、`(b)`、`(c)`；
- 不添加子图标题；
- 不添加整图标题。

## 5. 图例

只允许两种模式：

1. 所有子图共用同一图例：放在整张图正上方；
2. 子图图例不同：分别放在各子图正上方。

图例必须位于坐标轴外部，使用无边框样式。禁止使用 `loc="best"`。
图例是整张图最上方的元素，不得被其他文字遮挡。

## 6. 字体

字体配置：

```python
plt.rcParams["font.family"] = ["Times New Roman", "SimSun"]
plt.rcParams["axes.unicode_minus"] = False
```

- 中文使用宋体；
- 英文、数字、单位和角标使用 Times New Roman；
- 坐标标题优先中文，单位或特殊符号使用英文，例如 `时间 (s)`、`位置 (m)`；
- 坐标标题约 9 pt，刻度和图例约 8 pt；
- 出现缺字或字体回退警告时不得报告成功。

## 7. 坐标标题

- 每个独立坐标轴都需要完整的横纵标题；
- 共用横轴时，最下方子图显示横轴标题；
- 每个纵向子图显示自己的纵轴标题；
- 每个纵轴标题必须写出单位；
- 纵轴标题与刻度数字之间保持明显间距；
- 单位与源数据保持一致。

## 8. 输出合约

每张图输出两个文件：

```text
<output>\<figure_name>.svg
<output>\<figure_name>.png
```

- PNG 默认 300 dpi；
- SVG 与 PNG 布局一致；
- Matplotlib 不生成 MATLAB `.fig`；
- 不把不同主题拼接在一张图中；
- 用户未明确允许时不得覆盖已有输出；
- 每张图使用独立输出基名。

## 9. 验证

1. 绘图脚本退出码必须为 0；
2. SVG 和 PNG 都必须存在且大小非零；
3. PNG 在 300 dpi 下宽度应为 1653 或 1654 像素，对应约 140 mm；
4. SVG 宽度应约为 `396.85 pt`；
5. 图例不得被裁切；
6. 角标必须位于每个子图左上角，且没有其他子图标题；
7. 纵轴标题必须竖向、顶部对齐、不压刻度且包含单位；
8. 不得存在整图标题；
9. 标准错误中不得出现缺字、字体回退或布局警告。

已验证输出：

```text
PNG width: 1653 px at 300 dpi (139.95 mm)
SVG width: 396.850394 pt (140 mm)
```

## 10. 禁止模式

- 为少量简单计数或单个标量单独作图；这类信息优先用文字或表格表达，除非图形能揭示趋势、分布、关系或其他非显然模式；
- 图例放进子图内部；
- `loc="best"` 自动放置图例；
- 添加整图标题；
- 纵轴标题缺少单位；
- 子图标题而非字母角标；
- 缺少宋体或 Times New Roman；
- 使用 tight bounding box 改变固定宽度；
- 请求 SVG 时只输出 PNG；
- 多个不相关主题混在一张图中；
- 未检查导出文件就报告成功。
